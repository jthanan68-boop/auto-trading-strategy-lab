# Project rules

## The TODO list is part of every change

- `deploy/GITHUB_ACTIONS.md` carries the project's living **Status & TODO** list: what works, what is blocked, and what is next.
- Every change — code, workflow, dependency, deployment route — updates that list in the same commit. Tick what finished, add what the change uncovered, correct anything it made stale.
- A change that leaves the list describing the previous state is not finished.
- Keep it a status list, not a changelog: outstanding and blocking work lives there, shipped history lives in git.
